# Install

> **Status:** xpando has not had a public release yet. This page describes what the first releases are planned to ship. Until then you can build it yourself (see [[Contributing]]).

Releases will be published on the [Releases page](https://github.com/ultimatejimmy/xpando/releases). Versions are dates, such as `2026.11.23`; see [[Releasing]].

## Windows

Download the `.exe` installer (NSIS) from the latest release and run it.

## macOS

Download the `.dmg`, open it and drag xpando to Applications. macOS asks for permissions the first time (accessibility and input monitoring), because xpando has to see what you type to notice a trigger. Allow them in System Settings, Privacy and Security.

## Linux

Download the `.AppImage` or the `.deb`. Wayland support is experimental, as in espanso.

## Betas

Releases whose version ends in `-beta` (for example `2026.11.23-beta2`) are **pre-releases**. They are for testing and are never marked as "Latest" on the Releases page. Stable users only get stable releases.

## Already using espanso?

xpando keeps its own data and offers to copy your espanso phrases the first time it starts. Your espanso files are never changed. See [[Import from espanso]] and [[Data Folder]].
