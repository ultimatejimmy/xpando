# Screenshots for the wiki

This file is not published. The images in `images/` are generated, not captured by hand:
the real front end runs against demo data in a headless browser. To refresh them after a UI change,
follow [tools/marketing/README.md](../../tools/marketing/README.md), then copy the files from
`tools/marketing/out/wiki/` into `docs/wiki/images/` (keep the file names). The website uses the
same captures (`site/assets/`).
